1. PURE-ROBOCOPY C++20 & QT 6 ARCHITECTURE BLUEPRINT
--------------------------------------------------------------------------------

A major architectural limitation of standard Robocopy GUI wrappers is that when 
running robocopy.exe at maximum threads (/MT:128), parsing stdout alone either 
bottlenecks the console pipe or loses byte-level speed accuracy.

This native C++ architecture solves that by combining Non-Blocking Pipe Parsing 
(for file names, exclusions, and error logs) with Kernel Process I/O Telemetry 
(GetProcessIoCounters) polled directly against the robocopy.exe process handle 
every 16ms. Even when /MT:128 transfers 50,000 tiny files per second, the Windows 
kernel reports exact byte-level Read Speed, Write Speed, and IOPS with zero CPU 
overhead.

2. COMPLETE ROBOCOPY PARAMETER MATRIX (RADIO DOTS VS. CHECKBOXES)
--------------------------------------------------------------------------------

Every Robocopy parameter is mapped to either a Radio Button / Dot (•) for mutually 
exclusive choices, or a Checkbox [✓] for additive flags. The Smart High-Speed 
Default Profile is pre-selected on startup.

GROUP A: TRANSFER MODE — (Mutually Exclusive Radio Dots)
- (•) Copy All Subfolders (Including Empty) [/E] -> [DEFAULT]
      Copies the entire directory structure, preserving empty subfolders.
- ( ) Copy Non-Empty Subfolders Only [/S]
      Copies subdirectories containing files; discards empty directories.
- ( ) Root Folder Files Only (Level 1) [/LEV:1]
      Restricts file copying to the top-level root directory only.
- ( ) Move Files & Folders (Delete Source) [/MOVE]
      Moves files and directories, deleting them from the source after copying.
- ( ) Move Files Only (Keep Source Folders) [/MOV]
      Moves files, deleting them from source, but keeps directory structure intact.
- ( ) Mirror Directory (Exact Sync & Purge) [/MIR]
      Makes destination an exact replica of source, purging extra destination files.

GROUP B: COLLISION & OVERWRITE BEHAVIOR — (Mutually Exclusive Radio Dots)
- (•) Smart Delta Copy (Changed & Newer) [Default Robocopy Behavior] -> [DEFAULT]
      Copies new files and overwrites destination files if size or timestamp differs.
- ( ) Overwrite Older Only (Keep Newer Target) [/XO]
      Excludes older files; destination version is protected if it is newer.
- ( ) Skip All Existing Destination Files [/XC /XN /XO]
      Only copies files that do not exist at all in the destination.
- ( ) Force Overwrite Everything (Include Same) [/IS /IT]
      Forces re-copying even if destination files are completely identical.

GROUP C: ACCESS & RESILIENCE MODE — (Mutually Exclusive Radio Dots)
- (•) Standard Fast Kernel I/O [Default] -> [DEFAULT]
      Maximum local NVMe/SSD/HDD throughput without checkpoint or security overhead.
- ( ) Restartable Network Mode [/Z]
      Writes resume checkpoints inside partially copied files for flaky network connections.
- ( ) Backup Privilege Override Mode [/B]
      Uses SeBackupPrivilege and SeRestorePrivilege to bypass NTFS DACL restrictions (Admin).
- ( ) Restartable + Backup Fallback [/ZB]
      Tries Restartable mode first; falls back to Backup mode if access is denied.

GROUP D: MULTITHREADING, I/O & SPEED — (Checkboxes & Sliders)
- [✓] Maximum Multithreaded Transfer [/MT:128] -> [DEFAULT ON: 128 THREADS]
      Spawns 128 parallel Robocopy worker threads (slider range 1 to 128).
- [✓] Unbuffered Direct Disk I/O [/J] -> [DEFAULT ON]
      Bypasses system file caching for large files to eliminate RAM exhaustion.
- [ ] SMB Network Compression [/COMPRESS]
      Requests SMB 3.1.1 on-the-wire compression for network transfers.
- [ ] Disable Windows Copy Offload [/NOOFFLOAD]
      Forces standard host-side copy instead of hardware storage array offloading (ODX).
- [ ] Bandwidth Throttle (Inter-Packet Gap) [/IPG:n]
      Injects a 1-1000ms delay between packets to prevent network saturation.

GROUP E: FILE ATTRIBUTES, PERMISSIONS & LINKS — (Checkboxes)
- [✓] Copy File Data, Attributes & Timestamps [/COPY:DAT] -> [DEFAULT ON]
      Copies file payload, standard NTFS attributes, and modification timestamps.
- [✓] Preserve Directory Timestamps [/DCOPY:DAT] -> [DEFAULT ON]
      Keeps folder creation and modification timestamps synchronized.
- [✓] Exclude Junction Loops (Anti-Hang) [/XJ] -> [DEFAULT ON]
      Prevents infinite loops on Windows directory junctions and symlinks.
- [✓] FAT / NAS 2-Second Time Tolerance [/FFT] -> [DEFAULT ON]
      Prevents false re-copies when transferring between NTFS and exFAT/FAT32/NAS.
- [ ] Copy NTFS Security ACLs [/COPY:S] (/SEC)
      Transfers discretionary access control lists (requires matching domain/local SID).
- [ ] Copy File Ownership & Auditing Info [/COPY:OU] (/COPYALL)
      Transfers Owner and Auditing SACL information (requires UAC Administrator elevation).
- [ ] Copy Symbolic Links as Links (Not Targets) [/SL]
      Copies symlink pointers rather than the target data they reference.
- [ ] Fix Security & Timestamps on Skipped Files [/SECFIX /TIMFIX]
      Updates security metadata and timestamps even on files not copied.

GROUP F: RETRY LOGIC, FILTERING & VERIFICATION — (Checkboxes & Inputs)
- [✓] Fast Fail-Safe Retry Limit [/R:2 /W:2] -> [DEFAULT ON]
      Limits retries to 2 attempts waiting 2 seconds (overrides Robocopy's 1,000,000 retry hang).
- [ ] Wait for Network Share Registration [/TBD]
      Waits if network share names are resolving during boot or failover.
- [ ] Dry-Run Simulation Only (List Mode) [/L]
      Populates the UI diff grid with planned changes without committing disk writes.
- [ ] Create Zero-Byte Folder Skeleton Only [/CREATE]
      Creates destination directory hierarchy and 0-byte file shells.
- [ ] Exclude Extra Files & Folders Logs [/XX]
      Suppresses *EXTRA destination-only items from cluttering output.
- [ ] Exclude Lonely Files (Sync Existing Only) [/XL]
      Only updates files that already exist in the target folder.
- [ ] Filter by File / Folder Wildcards [/XF patterns /XD patterns]
      Excludes patterns like *.tmp, node_modules, .git, Thumbs.db.
- [ ] Filter by File Size Range [/MIN:n /MAX:n]
      Excludes files outside the specified byte size boundaries.
- [ ] Filter by File Age / Modified Date [/MAXAGE:n /MINAGE:n]
      Excludes files based on modification date thresholds.
- [ ] Post-Copy XXH3 / BLAKE3 Verification [Post-Pass]

### 4.2 Multi-Source Drag-and-Drop Batcher (MultiSourceBatcher.cpp)
TeraCopy allows users to drag and drop multiple distinct files and folders from different locations into a single target directory, whereas robocopy.exe syntax accepts only a single Source and Destination folder pair:
robocopy "<SourceDir>" "<DestDir>" [File1 File2 ...] [Flags]
Implement MultiSourceBatcher to solve this:
1. Partition dropped paths into Directories and Loose Files.
2. Group all Loose Files that share the same parent directory into a single RobocopyInvocation where Source = ParentDirectory, Dest = TargetRoot, and the file filter array contains "File1.ext" "File2.ext", automatically stripping /E or /S for that invocation so only those targeted files copy.
3. For each Directory D, create a RobocopyInvocation where Source = D, Dest = TargetRoot \ D.filename(), applying the user's full RobocopyProfile flags (/E, /MT:128, /J, etc.).
4. Execute invocations sequentially through RobocopyProcessSupervisor while aggregating total progress seamlessly across the entire batch.

### 4.3 Pure Robocopy Process Supervisor & Kernel Telemetry (RobocopyProcessSupervisor.cpp & KernelTelemetryPoller.cpp)
1. Process Execution:
   - Spawn C:\Windows\System32\robocopy.exe via CreateProcessW with CREATE_NO_WINDOW | CREATE_SUSPENDED and Unicode environment flags.
   - Attach the process handle to a Win32 Job Object configured with JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE so no zombie robocopy.exe processes survive if the UI closes.
   - Resume the process via ResumeThread.
2. True Hardware Pause / Resume:
   - Resolve NtSuspendProcess and NtResumeProcess from ntdll.dll.
   - When the user clicks Pause in the Liquid Glass HUD, call NtSuspendProcess(hProcess) to freeze all 128 Robocopy worker threads in kernel space immediately, pausing the ETA timer and throughput graph cleanly. Call NtResumeProcess(hProcess) on Resume.
3. 16ms Kernel I/O Telemetry (KernelTelemetryPoller.cpp):
   - Run a high-precision multimedia timer (16ms interval = 60Hz) calling GetProcessIoCounters(hRobocopyProcess, &ioCounters).
   - Compute instantaneous Read Speed (MB/s) from delta(ioCounters.ReadTransferCount) / deltaTime.
   - Compute instantaneous Write Speed (MB/s) from delta(ioCounters.WriteTransferCount) / deltaTime.
   - Compute instantaneous IOPS from delta(ioCounters.ReadOperationCount + ioCounters.WriteOperationCount) / deltaTime.
   - Compute Overall Batch Progress (0.0 to 100.0%) by dividing cumulative WriteTransferCount across the batch by the TotalBatchBytes discovered by FastPreScanner (FindFirstFileExW with FindExInfoBasic and FIND_FIRST_EX_LARGE_FETCH).
4. High-Speed Stdout Pipe Parser (StdoutPipeParser.cpp):
   - Append /V /TS /FP /BYTES /NJH /NJS /NDL /NP to robocopy.exe so Robocopy emits clean, single-line machine-parseable file entries without choking the pipe with carriage returns during /MT:128 execution.
   - Parse each line zero-copy using std::string_view to extract the status classification (New File, Newer, Older, same, *EXTRA File, ERROR), file size in bytes, and full path.
   - Push parsed entries into FileTransferListModel via a lock-free ring buffer flushed on the UI frame tick.
5. Robocopy Exit Code Bitmask Decoder:
   - Decode the exit code of robocopy.exe accurately:
     - 0: No files copied (already synchronized).
     - 1: All files copied successfully.
     - 2: Extra files or directories were detected.
     - 4: Mismatched files or directories were detected.
     - 8: Some files or directories could not be copied (copy errors occurred and retry limit was exceeded).
     - 16: Serious fatal error (invalid command-line usage or insufficient privileges).
   - Any exit code < 8 is treated as Success (with informational badges for 2 and 4). Exit codes >= 8 trigger the crimson Liquid Glass error state and highlight failed files in the workbench grid.
